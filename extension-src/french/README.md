Le pack de langue française officiel pour **RawanIDE**. Cette extension fournit une traduction complète, native et précise de l'interface utilisateur (IDE) en français.

### Caractéristiques
* Traduction complète de tous les menus, paramètres et outils de l'éditeur.
* Terminologie technique native adaptée aux environnements de développement intégrés (IDE).
* Intégration transparente avec l'interface de RawanIDE.

### Installation
1. Ouvrez **RawanIDE**.
2. Accédez à la section **Extensions** > **Marketplace**.
3. Recherchez `French Language Pack`.
4. Cliquez sur **Installer** (Install) et définissez la langue depuis les paramètres.

*(Pour une installation manuelle, téléchargez le fichier `.r1` et ouvrez-le via le gestionnaire de fichiers de RawanIDE).*

## English

The official French language pack for **RawanIDE**. This extension provides a complete, native, and accurate translation of the user interface into French.

### Features
* Complete translation of all menus, settings, and editor tools.
* Native technical terminology tailored for Integrated Development Environments (IDEs).
* Seamless integration with the RawanIDE interface.

### Installation
1. Open **RawanIDE**.
2. Navigate to the **Extensions** > **Marketplace** section.
3. Search for `French Language Pack`.
4. Click **Install** and set the language from the preferences.

*(For manual installation, download the `.r1` file and open it via the RawanIDE file manager).*

## العربية

حزمة اللغة الفرنسية الرسمية لبيئة التطوير **RawanIDE**. توفر هذه الإضافة ترجمة فرنسية كاملة، دقيقة، واحترافية لواجهة المستخدم.

### المميزات
* ترجمة شاملة لجميع القوائم، الإعدادات، وأدوات المحرر.
* استخدام مصطلحات تقنية دقيقة ومخصصة لبيئات التطوير المتكاملة (IDE).
* توافق واندماج تام مع واجهة RawanIDE.

### طريقة التثبيت
1. افتح تطبيق **RawanIDE**.
2. توجه إلى قسم **الإضافات (Extensions)** ثم **السوق (Marketplace)**.
3. ابحث عن `French Language Pack`.
4. اضغط على **تثبيت (Install)**، ثم قم بتغيير لغة الواجهة من الإعدادات.

*(للتثبيت اليدوي، قم بتحميل ملف `.r1` وافتحه مباشرة عبر مدير ملفات RawanIDE).*
