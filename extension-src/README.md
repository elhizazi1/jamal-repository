# Jamal Example

A small declarative extension for RawanIDE by Jamal El Hizazi.

- Snippets: `clg`, `afn`, `fetchj` (JavaScript), `jcard` (HTML), `jcenter`, `jvars` (CSS), `pmain` (Python).
- Commands: insert a file header for JS/CSS or HTML (from the ⌘ commands palette).
- Terminal theme: Jamal Night (Settings → Terminal).

It asks for no permissions and contains no executable code.
